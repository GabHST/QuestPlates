## PT-BR

QuestPlates adiciona um **"!"** dourado nas nameplates de mobs relacionados as suas quests ativas — igual o WoW moderno, mas para Vanilla 1.12.1.

### Funcionalidades
- **"!"** dourado nas nameplates de mobs de quest
- **Quests de matar**: marca mobs que precisa abater
- **Quests de item**: usa o banco de dados do pfQuest pra achar quais mobs dropam seus itens
- **Loot tables compartilhadas**: resolve tabelas de referencia pra marcacao precisa
- **Leve**: uso minimo de CPU (~5 FPS de verificacao)
- **Auto-atualiza**: re-escaneia objetivos ao aceitar, entregar e progredir quests

### Requisitos
- [pfUI](https://github.com/shagu/pfUI)
- [pfQuest](https://github.com/shagu/pfQuest)

### Instalacao
1. Baixe o ZIP da release mais recente
2. Extraia a pasta `QuestPlates` em `WoW/Interface/AddOns/`
3. Reinicie o WoW ou `/reload`

## EN

QuestPlates adds a golden **"!"** icon to the nameplates of mobs related to your active quests — just like modern WoW, but for Vanilla 1.12.1.

### Features
- Golden **"!"** icon on nameplates for quest objective mobs
- **Kill quests**: directly marks mobs you need to slay
- **Item drop quests**: uses pfQuest's database to find which mobs drop your quest items
- **Reference loot support**: resolves shared loot tables for accurate mob marking
- **Lightweight**: minimal CPU usage (~5 FPS check cycle)
- **Auto-updates**: re-scans objectives on quest accept, turn-in, and progress

### Requirements
- [pfUI](https://github.com/shagu/pfUI)
- [pfQuest](https://github.com/shagu/pfQuest)

### Installation
1. Download the latest release ZIP
2. Extract `QuestPlates` folder into `WoW/Interface/AddOns/`
3. Restart WoW or `/reload`
